# 🃏 Registro de partidas PTCG

App web local para registrar y analizar tus partidas de **Pokémon TCG Live**: importas tu mazo, eliges tus premios al empezar, pegas el log al terminar y la app detecta contra qué mazo has jugado y te enseña tus porcentajes de victoria.

> [!NOTE]
> **En desarrollo.** La primera versión (0.0.1) llega en el primer pull request.

## 🎯 Objetivo

- Guardar varios mazos importados desde TCG Live y marcar uno como el actual.
- Crear cada partida eligiendo las 6 cartas de Premio y marcar después cuáles se cogieron.
- Leer el log de la partida para sacar el resultado, quién empezó, los turnos y el mazo del rival.
- Mantener a mano una lista de mazos del meta con la que detectar al rival.
- Ver el historial y el porcentaje de victorias contra cada mazo rival.

Todo se guarda en el propio navegador: sin servidor, sin cuenta y sin conexión a internet.
